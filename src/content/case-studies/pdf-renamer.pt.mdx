<Tldr>
  Fiz uma ferramenta que lê PDFs escaneados e sugere o nome certo de cada um. Resultado: a
  secretaria passou de **~100 para ~300 documentos por dia**, e uma turma que levava 3 dias agora
  sai em até 1.
</Tldr>

## O problema

Imagina abrir um PDF chamado `scan_0412.pdf`, ler até descobrir que é um RG, digitar
`RG_2026.pdf`, achar a pasta do aluno e salvar. Agora repete isso **200 vezes**, que é mais ou menos
uma turma. Eram **3 dias** só nisso.

E não era só lento. Nome digitado à mão vira bagunça ("Ficha medica", "FICHA MÉDICA",
"ficha_saude"), e um arquivo salvo na pasta errada simplesmente some do prontuário do aluno.

## Onde eu entro

Eu trabalho nessa secretaria, então senti o problema na pele. Fiz tudo sozinho: achei o gargalo,
desenhei o fluxo, programei e acompanhei o uso. Hoje a equipe usa **todo dia**.

## As regras do jogo

Nada de solução "do jeito fácil". Eu tinha que respeitar quatro limites:

- **Nada de instalar programa**: tinha que rodar no navegador dos computadores da escola.
- **Os arquivos são locais**: os prontuários ficam em pastas do Windows, não num servidor.
- **Muito PDF é só imagem**: escaneado, sem texto para pesquisar.
- **Quem usa não programa**: os tipos de documento mudam por setor, então ajustar não podia depender
  de mim.

## Detalhes que eu curti

### O classificador cabe numa tela

O texto é normalizado (sem acento, tudo maiúsculo), cada tipo soma os pesos das palavras que
encontrou, e o vencedor só é sugerido se passar do limiar. É isso. Sem mágica.

```js title="js/script.js (resumido)"
function scoreKeyword(text, kw) {
  // termos curtos exigem palavra inteira (evita "RG" casar dentro de outra palavra)
  if (kw.length <= 3) return new RegExp("\\b" + kw + "\\b").test(text);
  return text.includes(kw);
}

function classify(text) {
  const t = normalizeText(text);
  let best = null,
    bestScore = 0;
  for (const rule of CLASSIFY_RULES) {
    let score = 0;
    for (const [kw, w] of rule.kw) if (scoreKeyword(t, kw)) score += w;
    if (score > bestScore) {
      bestScore = score;
      best = rule.type;
    }
  }
  return bestScore >= CLASSIFY_THRESHOLD ? { type: best, score: bestScore } : null;
}
```

As regras padrão convivem com as que a equipe cria: um setor adiciona uma palavra com um peso e ela
passa a valer na hora.

### Feito para quem usa o dia inteiro

- **Duplicados**: se o nome já existe na pasta, a ferramenta pergunta e sugere uma numeração livre.
- **Teclado**: atalhos para confirmar, pular e navegar, sem tirar a mão do teclado no meio do lote.
- **Histórico em CSV** de tudo o que foi renomeado.

### E tem IA também

Na versão que a secretaria usa, o PDF vai inteiro para a **API da Anthropic (Claude)**, que lê o
documento e já sugere o nome. Se não vier sugestão, a pessoa escolhe o tipo numa lista e o arquivo
continua aberto para conferir. O repositório público mostra a versão com OCR e regras; a integração
com a API não está nele.
