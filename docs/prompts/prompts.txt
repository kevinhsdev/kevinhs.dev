# Cobe Globe — ProfitizeBuild
Objetivo: um globo 3D em React que gira sozinho numa página branca, desenhado em WebGL pelo cobe: o mapa do mundo em pontos, nove cidades marcadas em azul, dois arcos entre elas e rótulos presos aos pontos, que somem com um desfoque quando a cidade passa para trás do globo. Arraste para girar: solto, o globo segue no embalo e desacelera; na vertical ele inclina até um limite e volta.

Contexto
  O desenho é do cobe 2.0.1 (WebGL, uns 5 KB, sem dependências): o mapa, o brilho, os pontos e os arcos. O giro, o arraste e os rótulos são do componente.
  Os rótulos usam CSS Anchor Positioning: o cobe cria uma âncora invisível em cada ponto e uma variável que diz se ele está na frente do globo. Funciona no Chrome, no Edge e no Safari 26+; num navegador sem anchor positioning, o globo aparece sem os rótulos, em vez de empilhá-los num canto.
  O componente cria o canvas dentro dele, fora do React (o cobe embrulha o canvas numa div própria), e dá um id a cada globo: dois globos na mesma página não trocam os rótulos entre si.
  O giro anda pelo tempo, não por quadro: a mesma velocidade a 60 e a 120 Hz. Fora da tela o globo para de desenhar; com "reduzir movimento" ligado no sistema, ele só gira quando é arrastado.
  React (18 ou 19), TypeScript e o pacote cobe. Sem Tailwind e sem outras bibliotecas: o CSS mora dentro do componente, numa <style>, com classes cg-*. Os rótulos e a demo declaram a própria tipografia e o box-sizing, então não herdam nada da página e ficam iguais em qualquer projeto.

Antes de começar
  Olhe a stack do projeto:
  - React com TypeScript (Next.js, Vite, Remix, Astro com React…): siga os passos abaixo. Os arquivos começam com "use client", que o Next.js exige e os outros ignoram.
  - React sem TypeScript: crie os arquivos como .jsx e tire só as anotações de tipo (os blocos interface e type, os ": Tipo", os "as Tipo", os "type" dentro dos imports e os genéricos <…>). Não mude mais nada.
  - Sem React (HTML puro, Vue, Svelte, Angular…): pare e me avise antes de fazer qualquer coisa; este componente é React.
  Os arquivos vão na pasta de componentes do projeto (src/components ou components). O componente fica numa subpasta ui, como na estrutura do shadcn; se o projeto já tem components/ui, use essa.
  Instale só o cobe, na versão exata (o desenho muda entre versões): npm install cobe@2.0.1 --save-exact. Com pnpm, pnpm add cobe@2.0.1 --save-exact; com yarn, yarn add cobe@2.0.1 --exact; com bun, bun add cobe@2.0.1 --exact. Nada mais.
  Mesmo que o projeto use Tailwind ou shadcn, não converta o CSS em classes utilitárias nem o mova para um .css separado.

```tsx
"use client"

import * as React from "react"
import createGlobe from "cobe"

/**
 * Cobe Globe — um globo 3D em WebGL que gira sozinho, com pontos nas cidades, arcos entre elas e rótulos presos aos
 * pontos, que somem com um desfoque quando o ponto passa para trás do globo.
 *
 * O desenho é do cobe (WebGL, uns 5 KB): o mapa em pontos, o brilho e os marcadores. Arraste para girar: solto, o globo
 * segue no embalo e desacelera; na vertical ele inclina até um limite e volta. Os rótulos usam CSS Anchor Positioning
 * (Chrome, Edge, Safari 26+); nos navegadores sem ele, o globo aparece sem os rótulos.
 *
 * O giro, o embalo e a volta da inclinação andam pelo tempo, não por quadro: o globo gira na mesma velocidade a 60 e a
 * 120 Hz. Fora da tela ele para de desenhar; com "reduzir movimento" ligado no sistema, só gira quando é arrastado.
 *
 * O canvas nasce aqui dentro, fora do React: o cobe embrulha o canvas numa div dele, e um canvas do React mudaria de
 * lugar debaixo dele. Os nomes das âncoras levam um id deste globo, então dois globos na mesma página não trocam os
 * rótulos entre si.
 */

export interface GlobeMarker {
  id: string
  location: [number, number]
  label: string
}

export interface GlobeArc {
  id: string
  from: [number, number]
  to: [number, number]
  label?: string
}

type RGB = [number, number, number]

export interface GlobeProps {
  markers?: GlobeMarker[]
  arcs?: GlobeArc[]
  className?: string
  style?: React.CSSProperties
  markerColor?: RGB
  baseColor?: RGB
  arcColor?: RGB
  glowColor?: RGB
  dark?: number
  mapBrightness?: number
  markerSize?: number
  markerElevation?: number
  arcWidth?: number
  arcHeight?: number
  speed?: number
  theta?: number
  diffuse?: number
  mapSamples?: number
}

type Settings = Required<Omit<GlobeProps, "className" | "style">>

// o cobe cria, para cada ponto e arco com id, uma âncora (--cobe-<id>, --cobe-arc-<id>) e uma variável de visibilidade
// (--cobe-visible-<id>, --cobe-visible-arc-<id>), as duas valendo para a página inteira. O id leva o deste globo na
// frente e só letras, números, - e _
const anchorId = (uid: string, id: string) => uid + "-" + id.replace(/[^a-zA-Z0-9_-]/g, "-")

// cada rótulo preso à âncora do ponto (ou do arco) e apagado, com desfoque, quando ele passa para trás do globo
const labelStyle = (name: string) =>
  ({
    positionAnchor: "--cobe-" + name,
    opacity: "var(--cobe-visible-" + name + ", 0)",
    filter: "blur(calc((1 - var(--cobe-visible-" + name + ", 0)) * 8px))",
  }) as React.CSSProperties

export function Globe({
  markers = [],
  arcs = [],
  className,
  style,
  markerColor = [0.3, 0.45, 0.85],
  baseColor = [1, 1, 1],
  arcColor = [0.3, 0.45, 0.85],
  glowColor = [0.94, 0.93, 0.91],
  dark = 0,
  mapBrightness = 10,
  markerSize = 0.025,
  markerElevation = 0.01,
  arcWidth = 0.5,
  arcHeight = 0.25,
  speed = 0.003,
  theta = 0.2,
  diffuse = 1.5,
  mapSamples = 16000,
}: GlobeProps) {
  const uid = "g" + React.useId().replace(/[^a-zA-Z0-9_-]/g, "")
  const stageRef = React.useRef<HTMLDivElement>(null)

  // o globo nasce uma vez; a cada quadro ele lê daqui as props mais novas (arrays escritos no JSX mudam a cada render)
  const settings: Settings = {
    markers,
    arcs,
    markerColor,
    baseColor,
    arcColor,
    glowColor,
    dark,
    mapBrightness,
    markerSize,
    markerElevation,
    arcWidth,
    arcHeight,
    speed,
    theta,
    diffuse,
    mapSamples,
  }
  const settingsRef = React.useRef(settings)
  React.useEffect(() => {
    settingsRef.current = settings
  })

  React.useEffect(() => {
    const stage = stageRef.current
    if (!stage) return
    const reduced = window.matchMedia("(prefers-reduced-motion: reduce)").matches
    const canvas = document.createElement("canvas")
    canvas.className = "cg-canvas"
    stage.append(canvas)

    let globe: ReturnType<typeof createGlobe> | null = null
    let raf = 0
    let last = 0
    let size = 0
    let visible = true
    let phi = 0
    let phiOffset = 0
    let thetaOffset = 0
    let drag = { phi: 0, theta: 0 }
    let velocity = { phi: 0, theta: 0 }
    let pointer: { x: number; y: number } | null = null
    let lastPointer: { x: number; y: number; t: number } | null = null

    const points = (s: Settings) => ({
      markers: s.markers.map((m) => ({ location: m.location, size: s.markerSize, id: anchorId(uid, m.id) })),
      arcs: s.arcs.map((a) => ({ from: a.from, to: a.to, id: anchorId(uid, a.id) })),
    })

    const frame = (now: number) => {
      raf = requestAnimationFrame(frame)
      // o passo, em quadros de 60 Hz, pelo tempo que passou: um quadro perdido conta no máximo como três
      const k = last ? Math.min(now - last, 50) / (1000 / 60) : 1
      last = now
      if (!globe || !visible) return
      const s = settingsRef.current
      if (!pointer) {
        if (!reduced) phi += s.speed * k
        if (Math.abs(velocity.phi) > 0.0001 || Math.abs(velocity.theta) > 0.0001) {
          phiOffset += velocity.phi * k
          thetaOffset += velocity.theta * k
          const decay = Math.pow(0.95, k)
          velocity.phi *= decay
          velocity.theta *= decay
        }
        // inclinado além do limite, volta devagar para dentro dele
        const pull = 1 - Math.pow(0.9, k)
        if (thetaOffset < -0.4) thetaOffset += (-0.4 - thetaOffset) * pull
        else if (thetaOffset > 0.4) thetaOffset += (0.4 - thetaOffset) * pull
      }
      globe.update({
        phi: phi + phiOffset + drag.phi,
        theta: s.theta + thetaOffset + drag.theta,
        dark: s.dark,
        mapBrightness: s.mapBrightness,
        markerColor: s.markerColor,
        baseColor: s.baseColor,
        arcColor: s.arcColor,
        markerElevation: s.markerElevation,
        ...points(s),
      })
    }

    const init = () => {
      size = canvas.offsetWidth
      if (!size) return
      const s = settingsRef.current
      globe = createGlobe(canvas, {
        devicePixelRatio: Math.min(window.devicePixelRatio || 1, 2),
        width: size,
        height: size,
        phi: 0,
        theta: s.theta,
        dark: s.dark,
        diffuse: s.diffuse,
        mapSamples: s.mapSamples,
        mapBrightness: s.mapBrightness,
        baseColor: s.baseColor,
        markerColor: s.markerColor,
        glowColor: s.glowColor,
        markerElevation: s.markerElevation,
        ...points(s),
        arcColor: s.arcColor,
        arcWidth: s.arcWidth,
        arcHeight: s.arcHeight,
        opacity: 0.7,
      })
      raf = requestAnimationFrame(frame)
      setTimeout(() => (canvas.style.opacity = "1"))
    }

    // o globo nasce quando o canvas ganha largura e acompanha a largura dele depois
    const ro = new ResizeObserver(() => {
      if (!globe) return init()
      const width = canvas.offsetWidth
      if (width && width !== size) {
        size = width
        globe.update({ width, height: width })
      }
    })
    ro.observe(canvas)
    const io = new IntersectionObserver(([e]) => {
      visible = e.isIntersecting
    })
    io.observe(stage)

    // arrastar: o globo segue a mão; solto, continua no embalo da última velocidade dela
    const down = (e: PointerEvent) => {
      pointer = { x: e.clientX, y: e.clientY }
      canvas.style.cursor = "grabbing"
    }
    const move = (e: PointerEvent) => {
      if (!pointer) return
      drag = { phi: (e.clientX - pointer.x) / 300, theta: (e.clientY - pointer.y) / 1000 }
      const now = performance.now()
      if (lastPointer) {
        const dt = Math.max(now - lastPointer.t, 1)
        const max = 0.15
        velocity = {
          phi: Math.max(-max, Math.min(max, ((e.clientX - lastPointer.x) / dt) * 0.3)),
          theta: Math.max(-max, Math.min(max, ((e.clientY - lastPointer.y) / dt) * 0.08)),
        }
      }
      lastPointer = { x: e.clientX, y: e.clientY, t: now }
    }
    const up = () => {
      if (pointer) {
        phiOffset += drag.phi
        thetaOffset += drag.theta
        drag = { phi: 0, theta: 0 }
        lastPointer = null
      }
      pointer = null
      canvas.style.cursor = "grab"
    }
    canvas.addEventListener("pointerdown", down)
    window.addEventListener("pointermove", move, { passive: true })
    window.addEventListener("pointerup", up, { passive: true })
    window.addEventListener("pointercancel", up, { passive: true })

    return () => {
      cancelAnimationFrame(raf)
      ro.disconnect()
      io.disconnect()
      canvas.removeEventListener("pointerdown", down)
      window.removeEventListener("pointermove", move)
      window.removeEventListener("pointerup", up)
      window.removeEventListener("pointercancel", up)
      if (globe) {
        globe.destroy()
        // o contexto sai na hora (o navegador segura uns 16 por página), e o canvas e a div do cobe saem junto
        const gl = canvas.getContext("webgl2") ?? canvas.getContext("webgl")
        gl?.getExtension("WEBGL_lose_context")?.loseContext()
      }
      stage.replaceChildren()
    }
  }, [uid])

  return (
    <div className={"cg-root" + (className ? " " + className : "")} style={style}>
      {/* o CSS cru: como filho de texto, o SSR do React 18 escaparia as aspas e quebraria os seletores */}
      <style dangerouslySetInnerHTML={{ __html: CG_CSS }} />
      <div ref={stageRef} className="cg-stage" />
      {markers.map((m) => (
        <div key={m.id} className="cg-label cg-label--marker" style={labelStyle(anchorId(uid, m.id))}>
          {m.label}
          <span className="cg-label__tip" />
        </div>
      ))}
      {arcs
        .filter((a) => a.label)
        .map((a) => (
          <div key={a.id} className="cg-label cg-label--arc" style={labelStyle("arc-" + anchorId(uid, a.id))}>
            {a.label}
            <span className="cg-label__tip" />
          </div>
        ))}
    </div>
  )
}
```

# Polaroid Line Carousel — ProfitizeBuild
Objetivo: um carrossel de fotos em React em que as fotos são polaroides presas por pregadores de madeira num varal que cede no meio. Arrastar o varal (ou usar as setas) faz as fotos deslizarem por ele, balançando nos pregadores com a velocidade que a pessoa deu e voltando ao lugar com um leve passo além; mesmo paradas, elas balançam numa brisa. A foto do meio é a que está à vista, com o título e a legenda embaixo. A demo são seis fotos de paisagem numa página creme, ocupando a tela inteira.

Contexto
  O varal é uma curva que vai de uma ponta à outra e cede no meio (sag, 46 px). As fotos ficam penduradas nele, uma ao lado da outra, cada uma com um pregador no topo e o título escrito à mão (em itálico, com serifa) na margem de baixo. A do meio fica na frente, inteira e com as cores cheias; as outras ficam um pouco menores e mais apagadas.
  Arrastar em qualquer lugar do carrossel leva o varal junto com o ponteiro; ao soltar, ele desliza até a foto mais perto do meio numa mola (contando a velocidade do arraste: um puxão rápido vai mais longe), e as fotos balançam para trás do movimento e se acalmam. Passar da primeira ou da última estica o varal com resistência, e ele volta. O clique numa foto a traz para o meio. As setas embaixo andam uma foto; com o carrossel em foco (Tab), ← e → também. Com autoplay (4,5 s por foto, o padrão), ele avança sozinho e volta à primeira depois da última, esperando enquanto alguém mexe nele. Embaixo, à esquerda, o título e a legenda da foto do meio entram de baixo para cima a cada troca; à direita, o contador (01 / 06) e as setas.
  O tamanho sai do próprio carrossel, não da tela: a foto tem até 300 px de largura e encolhe para caber (42% da largura e da altura do carrossel, no mínimo 150 px), e o varal passa a 20% da altura. No celular o dedo passa as fotos de lado e a rolagem da página para cima e para baixo continua funcionando. export function wrap(i: number, n: number): number {
```tsx
  return n ? ((i % n) + n) % n : 0
}

export function clamp(v: number, a: number, b: number): number {
  return Math.min(b, Math.max(a, v))
}

/** Altura de um varal que cede `sag` entre (0, y0) e (w, y0), no ponto x. */
export function stringY(x: number, w: number, y0: number, sag: number): number {
  const t = clamp(x / w, 0, 1)
  return y0 + 4 * sag * t * (1 - t)
}

/** Um passo de uma mola com amortecimento crítico até o alvo. */
export function springStep(x: number, v: number, target: number, dt: number, k = 70): [number, number] {
  const c = 2 * Math.sqrt(k)
  const nv = v + (k * (target - x) - c * v) * dt
  return [x + nv * dt, nv]
}

/** Um passo do balanço de uma foto. lineVel é a velocidade das fotos no varal (px/s, + = para a direita); a foto fica para trás do movimento, a gravidade a puxa de volta e o atrito a amortece. */
export function swingStep(a: number, w: number, lineVel: number, dt: number, gain: number): [number, number] {
  const nw = w + (-38 * a - 4.2 * w + lineVel * 0.0034 * gain) * dt
  return [clamp(a + nw * dt, -0.6, 0.6), nw]
}

/** Índice da foto mais perto do meio para um deslocamento do varal. */
export function nearestAt(off: number, spacing: number, n: number): number {
  return clamp(Math.round(off / spacing), 0, Math.max(0, n - 1))
}

export function pad2(n: number): string {
  return n < 10 ? "0" + n : String(n)
}

const PALETTES = {
  dawn: { top: "#e7b7a5", bottom: "#f8e8d6", sun: "#fff4df", far: "#d2b2bb", near: "#3a2a3b", mist: "255,240,232" },
  alpine: { top: "#7ea5c8", bottom: "#e3ecf2", sun: "#ffffff", far: "#a9bfd0", near: "#1c3044", mist: "236,244,250" },
  dusk: { top: "#2a2450", bottom: "#ef8d60", sun: "#ffd9a6", far: "#93607c", near: "#18121f", mist: "255,196,160" },
  mist: { top: "#c4d0cb", bottom: "#eef1ec", sun: "#ffffff", far: "#aebcb5", near: "#2c3a33", mist: "246,248,245" },
}

function mulberry32(seed: number): () => number {
  let a = seed >>> 0
  return () => {
    a = (a + 0x6d2b79f5) >>> 0
    let t = a
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}
function hexRgb(h: string): [number, number, number] {
  const v = parseInt(h.replace("#", ""), 16)
  return [(v >> 16) & 255, (v >> 8) & 255, v & 255]
}
function mixRgb(a: string, b: string, t: number): string {
  const A = hexRgb(a)
  const B = hexRgb(b)
  return "rgb(" + A.map((v, i) => Math.round(v + (B[i] - v) * t)).join(",") + ")"
}

// Uma paisagem de serras em camadas: o céu, um sol baixo, cinco serras sumindo na
// névoa com bruma entre elas, pinheiros na mais perto e o grão do filme. Pintada uma vez.
function paintLandscape(seed: number, palette: LandPalette, w = 1600, h = 1000): string {
  if (typeof document === "undefined") return ""
  const c = document.createElement("canvas")
  c.width = w
  c.height = h
  const g = c.getContext("2d")
  if (!g) return ""
  const P = PALETTES[palette] ?? PALETTES.dawn
  const r = mulberry32(seed * 104729 + 7)

  const sky = g.createLinearGradient(0, 0, 0, h * 0.72)
  sky.addColorStop(0, P.top)
  sky.addColorStop(1, P.bottom)
  g.fillStyle = sky
  g.fillRect(0, 0, w, h)
  const sx = w * (0.22 + r() * 0.56)
  const sy = h * (0.26 + r() * 0.16)
  const halo = g.createRadialGradient(sx, sy, 0, sx, sy, w * 0.45)
  halo.addColorStop(0, "rgba(" + hexRgb(P.sun).join(",") + ",.85)")
  halo.addColorStop(0.08, "rgba(" + hexRgb(P.sun).join(",") + ",.55)")
  halo.addColorStop(1, "rgba(" + hexRgb(P.sun).join(",") + ",0)")
  g.fillStyle = halo
  g.fillRect(0, 0, w, h)
  g.fillStyle = P.sun
  g.beginPath()
  g.arc(sx, sy, h * 0.045, 0, Math.PI * 2)
  g.fill()

  const layers = 5
  for (let L = 0; L < layers; L++) {
    const k = L / (layers - 1)
    const base = h * (0.42 + k * 0.4)
    const amp = h * (0.07 + k * 0.1)
    const ph = [r(), r(), r(), r()].map((v) => v * Math.PI * 2)
    const fr = [1.3 + r(), 3.1 + r() * 2, 7 + r() * 4, 17 + r() * 8]
    const ridge = (x: number) => {
      const u = x / w
      return (
        base -
        amp *
          (0.55 * Math.sin(u * fr[0] + ph[0]) +
            0.28 * Math.sin(u * fr[1] + ph[1]) +
            0.12 * Math.abs(Math.sin(u * fr[2] + ph[2])) +
            0.05 * Math.sin(u * fr[3] + ph[3]))
      )
    }
    const mist = g.createLinearGradient(0, base - amp * 1.4, 0, base + amp * 0.4)
    mist.addColorStop(0, "rgba(" + P.mist + ",0)")
    mist.addColorStop(1, "rgba(" + P.mist + "," + (0.55 - k * 0.35).toFixed(2) + ")")
    g.fillStyle = mist
    g.fillRect(0, base - amp * 1.4, w, amp * 1.8)
    const body = g.createLinearGradient(0, base - amp, 0, h)
    body.addColorStop(0, mixRgb(P.far, P.near, Math.pow(k, 1.3)))
    body.addColorStop(1, mixRgb(P.far, P.near, Math.min(1, Math.pow(k, 1.3) + 0.18)))
    g.fillStyle = body
    g.beginPath()
    g.moveTo(0, h)
    for (let x = 0; x <= w; x += 6) g.lineTo(x, ridge(x))
    g.lineTo(w, h)
    g.closePath()
    g.fill()
    if (L >= layers - 2) {
      g.fillStyle = mixRgb(P.far, P.near, Math.min(1, Math.pow(k, 1.3) + 0.08))
      for (let x = 0; x < w; x += 7 + r() * 9) {
        if (r() < 0.35) continue
        const y = ridge(x) + 2
        const th = h * (0.025 + r() * 0.035) * (0.6 + k)
        const tw = th * 0.32
        g.beginPath()
        g.moveTo(x, y - th)
        g.lineTo(x + tw, y)
        g.lineTo(x - tw, y)
        g.closePath()
        g.fill()
      }
    }
  }

  const vig = g.createRadialGradient(w / 2, h * 0.45, h * 0.3, w / 2, h / 2, w * 0.78)
  vig.addColorStop(0, "rgba(0,0,0,0)")
  vig.addColorStop(1, "rgba(0,0,0,.32)")
  g.fillStyle = vig
  g.fillRect(0, 0, w, h)
  const grain = g.getImageData(0, 0, w, h)
  const d = grain.data
  for (let i = 0; i < d.length; i += 4) {
    const v = (r() - 0.5) * 14
    d[i] += v
    d[i + 1] += v
    d[i + 2] += v
  }
  g.putImageData(grain, 0, 0)
  return c.toDataURL("image/jpeg", 0.88)
}

// Cada slide como o endereço de uma imagem; os sem imagem são pintados no primeiro quadro depois de montar.
function useSlideImages(slides: Slide[]): string[] {
  const key = slides.map((s) => s.image || (s.palette || "dawn") + ":" + (s.seed ?? 1)).join("|")
  const [painted, setPainted] = React.useState<{ key: string; srcs: string[] }>({ key: "", srcs: [] })
  React.useEffect(() => {
    if (slides.every((s) => s.image)) return
    const id = requestAnimationFrame(() =>
      setPainted({ key, srcs: slides.map((s, i) => (s.image ? "" : paintLandscape(s.seed ?? i + 1, s.palette || "dawn"))) }),
    )
    return () => cancelAnimationFrame(id)
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [key])
  return slides.map((s, i) => s.image || (painted.key === key ? painted.srcs[i] : "") || "")
}

        lineVel = d.v * 1000
      } else {
        const before = S.off
        ;[S.off, S.vel] = springStep(S.off, S.vel, S.target, dt)
        lineVel = -(S.off - before) / Math.max(dt, 1e-3)
      }
      const o = opts.current
      const g = reduce ? 0 : o.swing
      const near = nearestAt(S.off, spacing, n)
      for (let i = 0; i < n; i++) {
        const el = cards.current[i]
        if (!el) continue
        const x = w / 2 + i * spacing - S.off
        if (x < -cw * 1.5 || x > w + cw * 1.5) {
          el.style.visibility = "hidden"
          continue
        }
        el.style.visibility = "visible"
        let a = S.a[i] || 0
        let av = S.w[i] || 0
        ;[a, av] = swingStep(a, av, lineVel, dt, g)
        if (g) a += Math.sin(now / 1300 + i * 1.7) * 0.0009 * g
        S.a[i] = a
        S.w[i] = av
        const y = stringY(x, w, y0, o.sag) - 6
        el.style.transform = "translate(" + (x - cw / 2).toFixed(1) + "px," + y.toFixed(1) + "px) rotate(" + a.toFixed(4) + "rad)"
        el.style.zIndex = String(i === near ? n + 1 : n - Math.abs(i - near))
      }
      pathRef.current?.setAttribute("d", "M0 " + y0 + " Q" + w / 2 + " " + (y0 + 2 * o.sag) + " " + w + " " + y0)
      if (near !== activeRef.current) {
        activeRef.current = near
        setActive(near)
      }
      raf = requestAnimationFrame(frame)
    }
    const io = new IntersectionObserver(([e]) => {
      visible = e.isIntersecting
      if (visible && !raf) {
        prev = performance.now()
        raf = requestAnimationFrame(frame)
      }
    })
    io.observe(root)
    raf = requestAnimationFrame(frame)
    return () => {
      cancelAnimationFrame(raf)
      io.disconnect()
    }
  }, [size, spacing, n])

  // autoplay, de volta à primeira foto depois da última
  React.useEffect(() => {
    if (!autoplay || n < 2) return
    const t = window.setInterval(() => {
      if (document.hidden || drag.current || performance.now() - lastTouch.current < autoplay) return
      goTo(activeRef.current >= n - 1 ? 0 : activeRef.current + 1)
    }, autoplay)
    return () => window.clearInterval(t)
  }, [autoplay, n, goTo])

  // o ponteiro anda em px da tela; o varal, nos do próprio layout: k desconta a escala de um transform em volta
  const onDown = (e: React.PointerEvent) => {
    if (e.button > 0 || (e.target as HTMLElement).closest(".pl-bar")) return
    lastTouch.current = performance.now()
    const k = rootRef.current ? screenScale(rootRef.current) : 1
    drag.current = { x: e.clientX, off: sim.current.off, lx: e.clientX, lt: e.timeStamp, v: 0, k, moved: false }
  }
  const onMove = (e: React.PointerEvent) => {
    const d = drag.current
    if (!d) return
    const dx = (e.clientX - d.x) / d.k
    if (!d.moved && Math.abs(dx) * d.k > 5) {
      d.moved = true
      setDragging(true)
      try {
        rootRef.current?.setPointerCapture(e.pointerId)
      } catch {
        // o ponteiro já foi embora: o arraste segue sem a captura
      }
    }
    if (!d.moved) return
    const dt = Math.max(1, e.timeStamp - d.lt)
    d.v = 0.7 * ((e.clientX - d.lx) / d.k / dt) + 0.3 * d.v
    d.lx = e.clientX
    d.lt = e.timeStamp
    const max = (n - 1) * spacing
    let off = d.off - dx
    if (off < 0) off *= 0.35
    if (off > max) off = max + (off - max) * 0.35
    sim.current.off = off
  }
  const onUp = (e: React.PointerEvent) => {
    const d = drag.current
    drag.current = null
    lastTouch.current = performance.now()
    if (!d) return
    if (d.moved) {
      setDragging(false)
      sim.current.vel = -d.v * 1000
      goTo(nearestAt(sim.current.off - d.v * 180, spacing, n))
      return
    }
    const card = (e.target as HTMLElement).closest("[data-i]")
    if (card) goTo(Number(card.getAttribute("data-i")))
  }
  const step = (dir: number) => {
    lastTouch.current = performance.now()
    goTo(clamp(activeRef.current + dir, 0, n - 1))
  }
  const onKey = (e: React.KeyboardEvent) => {
    if (e.key === "ArrowRight") step(1)
    else if (e.key === "ArrowLeft") step(-1)
    else return
    e.preventDefault()
  }

  const s = slides[active] || {}

  return (
    <div
      ref={rootRef}
      className={["pl-root", className].filter(Boolean).join(" ")}
      style={{
        height,
        ["--pl-bg" as string]: background,
        ["--pl-ink" as string]: ink,
        ["--pl-muted" as string]: "color-mix(in srgb, var(--pl-ink) 55%, transparent)",
        ["--pl-line" as string]: "color-mix(in srgb, var(--pl-ink) 18%, transparent)",
        ["--pl-cw" as string]: size.cw + "px",
        ...style,
      }}
      data-drag={dragging ? "1" : "0"}
      role="region"
      aria-roledescription="carrossel"
      aria-label={ariaLabel}
      tabIndex={0}
      onKeyDown={onKey}
      onPointerDown={onDown}
      onPointerMove={onMove}
      onPointerUp={onUp}
      onPointerCancel={onUp}
    >
      <PolaroidLineStyles />
      <svg className="pl-string" aria-hidden="true">
        <path ref={pathRef} fill="none" stroke={string} strokeWidth="1.5" strokeLinecap="round" />
      </svg>
      {slides.map((sl, i) => (
        <div
          key={i}
          className="pl-card"
          data-i={i}
          data-on={i === active ? "1" : "0"}
          ref={(el) => void (cards.current[i] = el)}
          aria-hidden={i === active ? undefined : true}
        >
          <div className="pl-print">
            <div className="pl-shot">{srcs[i] ? <img src={srcs[i]} alt={sl.alt || sl.title || ""} draggable={false} /> : null}</div>
            <div className="pl-note">{sl.title || ""}</div>
          </div>
          <div className="pl-peg" />
        </div>
      ))}
      <div className="pl-bar">
        <div className="pl-cap" key={active} aria-hidden="true">
          {s.title ? <span className="pl-title">{s.title}</span> : null}
          {s.caption ? <span className="pl-sub">{s.caption}</span> : null}
        </div>
        <span className="pl-count" aria-hidden="true">
          <b>{pad2(active + 1)}</b> / {pad2(n)}
        </span>
        <button type="button" className="pl-btn" aria-label={L.previous} onClick={() => step(-1)}>
          <svg width="16" height="16" viewBox="0 0 16 16" fill="none" aria-hidden="true">
            <path d="M10 3 5 8l5 5" stroke="currentColor" strokeWidth="1.4" />
          </svg>
        </button>
        <button type="button" className="pl-btn" aria-label={L.next} onClick={() => step(1)}>
          <svg width="16" height="16" viewBox="0 0 16 16" fill="none" aria-hidden="true">
            <path d="m6 3 5 5-5 5" stroke="currentColor" strokeWidth="1.4" />
          </svg>
        </button>
      </div>
      <div className="pl-sr" aria-live="polite">
        {L.status(active + 1, n, s.title)}
      </div>
    </div>
  )
}
```

```tsx
export type SelectorOption = {
  title: string
  description?: string

  image: string
  /** Um ícone de 24 px, que pinta com currentColor (branco). */

  /** A opção aberta, para controlar de fora; com ela, a troca chega por onIndexChange. */

// O React 19 sobe uma <style> com href e precedence para o <head>, uma vez só para todas as faixas (fora da faixa e do

// filho de texto o SSR do 18 escaparia as aspas e quebraria os seletores.
const HOISTS_STYLES = Number(React.version.split(".")[0]) >= 19

function InteractiveSelectorStyles() {
  if (HOISTS_STYLES) {
    const hoist = { href: "interactive-selector", precedence: "default" } as React.StyleHTMLAttributes<HTMLStyleElement>
    return <style {...hoist}>{ISEL_CSS}</style>
  }
  return <style hidden dangerouslySetInnerHTML={{ __html: ISEL_CSS }} />
}

export const InteractiveSelector = React.forwardRef<HTMLDivElement, InteractiveSelectorProps>(function InteractiveSelector(
  { options, defaultIndex = 0, index, onIndexChange, label = "Opções", className, ...props },
  ref,
) {
  const [inner, setInner] = React.useState(defaultIndex)
  const [shown, setShown] = React.useState(false)
  const root = React.useRef<HTMLDivElement | null>(null)
  const items = React.useRef<(HTMLButtonElement | null)[]>([])
  const active = Math.min(Math.max(index ?? inner, 0), options.length - 1)

  const setRoot = React.useCallback(
    (node: HTMLDivElement | null) => {
      root.current = node
      if (typeof ref === "function") ref(node)
      else if (ref) ref.current = node
    },
    [ref],
  )

  // a entrada espera a faixa aparecer na tela

    const el = root.current
    if (!el || typeof IntersectionObserver === "undefined") {
      setShown(true)
      return
    }
    const io = new IntersectionObserver(
      entries => {
        if (entries.some(e => e.isIntersecting)) {
          setShown(true)
          io.disconnect()
        }
      },
      { threshold: 0.15 },
    )
    io.observe(el)
    return () => io.disconnect()
  }, [])

  const select = (i: number) => {
    if (i === active) return
    if (index === undefined) setInner(i)
    onIndexChange?.(i)
  }

  const onKeyDown = (e: React.KeyboardEvent<HTMLDivElement>) => {
    const n = options.length
    let next: number
    switch (e.key) {
      case "ArrowRight":
      case "ArrowDown":
        next = (active + 1) % n
        break
      case "ArrowLeft":
      case "ArrowUp":
        next = (active - 1 + n) % n
        break
      case "Home":
        next = 0
        break
      case "End":
        next = n - 1
        break
      default:
        return
    }
    e.preventDefault()
    select(next)
    items.current[next]?.focus()
  }

  return (
    <div ref={setRoot} className={"isel" + (className ? " " + className : "")} data-shown={shown || undefined} {...props}>
      <InteractiveSelectorStyles />
      <div className="isel__list" role="radiogroup" aria-label={label} onKeyDown={onKeyDown}>
        {options.map((option, i) => (
          <button
            key={i}
            ref={el => {
              items.current[i] = el
            }}
            className="isel__option"
            type="button"
            role="radio"
            aria-checked={i === active}
            tabIndex={i === active ? 0 : -1}
            style={{ "--isel-i": i } as React.CSSProperties}
            onClick={() => select(i)}
          >
            <img className="isel__img" src={option.image} alt="" decoding="async" draggable={false} />
            <span className="isel__shade" aria-hidden="true" />
            <span className="isel__label">
              <span className="isel__icon" aria-hidden="true">
                {option.icon}
              </span>
              <span className="isel__info">
                <span className="isel__title">{option.title}</span>
                {option.description != null && <span className="isel__desc">{option.description}</span>}
              </span>
            </span>
          </button>
        ))}
      </div>
    </div>
  )
})
```
